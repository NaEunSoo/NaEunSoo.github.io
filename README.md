## 문제 1: 다이오드의 특성과 동작 원리

**난이도**: 🟢 쉬움  
**주제**: 다이오드

### 문제
다이오드에 대한 다음 물음에 답하시오.

1. 다이오드의 순방향 바이어스와 역방향 바이어스를 설명하시오.
2. 실리콘 다이오드의 순방향 전압강하는 약 몇 V인가?
3. 제너 다이오드의 용도를 설명하시오.

### 정답 및 해설

1. **순방향/역방향 바이어스:**
   - 순방향 바이어스: P형에 (+), N형에 (-)를 연결하여 전류가 흐르는 상태
   - 역방향 바이어스: P형에 (-), N형에 (+)를 연결하여 전류가 거의 흐르지 않는 상태

2. **순방향 전압강하:** 약 0.7V (실리콘), 0.3V (게르마늄)

3. **제너 다이오드 용도:** 정전압 회로, 전압 안정화 회로에 사용

## 문제 4: 트랜지스터 바이어스 회로 계산

**난이도**: 🟡 보통  
**주제**: 트랜지스터

### 문제
다음 고정 바이어스 회로에서 물음에 답하시오.

**회로 조건:**
- Vcc = 12V
- Rb = 470kΩ
- Rc = 2.2kΩ
- β = 100

1. 베이스 전류(Ib)를 구하시오. (Vbe = 0.7V)
2. 컬렉터 전류(Ic)를 구하시오.
3. 컬렉터-이미터 전압(Vce)을 구하시오.

### 정답 및 해설

1. **베이스 전류 계산:**
   ```
   Ib = (Vcc - Vbe) / Rb = (12 - 0.7) / 470k ≈ 24μA
   ```

2. **컬렉터 전류 계산:**
   ```
   Ic = β × Ib = 100 × 24μA = 2.4mA
   ```

3. **Vce 계산:**
   ```
   Vce = Vcc - Ic × Rc = 12 - (2.4m × 2.2k) ≈ 6.72V
   ```

   R1 = 22kΩ, R2 = 150kΩ (예시)

**설계 목표:**
- 총 전압 이득 100배
- 입력 임피던스 > 10kΩ
- 1단: 이미터 접지
- 2단: 컬렉터 접지

1. 각 단의 전압 이득을 어떻게 배분하는 것이 좋은가?

   - **직접 결합:** DC~고주파 증폭, 드리프트 문제, IC에 적합
